Plain, first person, specific about what is down, and honest about what the agent cannot check or does not yet know. Entry for make.fun's "The Most Honest Outage Line" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

Writes the entry line to `/output/entry.txt`.
